🚀 Démarrage Rapide

1 Configuration initiale
  • Ouvrez config.php
  • Modifiez les paramètres de connexion SQL Server
  • Enregistrez le fichier
2 Création de la base de données
  • Ouvrez SQL Server Management Studio
  • Exécutez le script code.sql
  • Exécutez le script alimentation.sql (optionnel - données de test)
3 Accès au site
  • Ouvrez votre navigateur
  • Accédez à http://localhost/portfolio/admin.php
  • Vérifiez que la connexion est établie
✅ Félicitations ! Votre portfolio est prêt à être utilisé.

📋 Fonctionnalités Détaillées

👤

Gestion du Profil

Modifiez vos informations personnelles :

  • Nom et prénom
  • Email et téléphone
  • Description professionnelle
  • Liste des expériences en aperçu

💡 Astuce : Rédigez une description accrocheuse qui résume votre profil en quelques lignes.

🎓

Gestion des Formations

Documentez votre parcours académique :

  • Ajoutez vos diplômes et certifications
  • Indiquez l'établissement et la ville
  • Précisez les dates (début et fin)
  • Ajoutez une description (optionnelle)

💡 Astuce : Commencez par la formation la plus récente.

ℹ️ Affichage : Les formations sont présentées en timeline chronologique inversée.
💼

Gestion des Expériences

Valorisez votre parcours professionnel :

  • Titre du poste
  • Entreprise ou organisation
  • Dates de début et fin (laisser vide si en cours)
  • Missions et réalisations
  • Association avec un projet (optionnel)

💡 Astuce pour les réalisations : Écrivez une réalisation par ligne pour qu'elles s'affichent sous forme de liste à puces.

✨ Fonctionnalité : Les descriptions longues affichent un bouton "Lire plus" automatiquement.
📁

Gestion des Projets

Présentez vos réalisations techniques :

  • Titre du projet
  • Description détaillée
  • Technologies utilisées (séparées par des virgules)
  • Lien vers le code source (GitHub, GitLab...)
  • Lien vers une démo en ligne
  • Dates de réalisation
  • Compétences associées (sélection multiple)

💡 Astuce : Associez vos compétences aux projets pour créer des liens cohérents.

ℹ️ Affichage : Les projets sont présentés en grille de cartes avec code couleur.
🏆

Gestion des Compétences

Organisez vos compétences techniques :

  • Nom de la compétence (ex: Python, SQL Server...)
  • Catégorie (ex: Langages, Outils, SGBD...)
  • Niveau de maîtrise (Débutant, Intermédiaire, Avancé, Expert)

💡 Astuce : Créez des catégories pour regrouper vos compétences (Développement Web, Data Science, etc.)

⚠️ Points Importants

🔐 Sécurité :

Ce portfolio ne possède pas de système d'authentification. Pour une utilisation en production, ajoutez un système de connexion sécurisé.

💾 Sauvegarde :

Pensez à effectuer des sauvegardes régulières de votre base de données SQL Server.

🌐 Compatibilité :

Le site est compatible avec tous les navigateurs modernes (Chrome, Firefox, Edge, Safari).

💡 Conseils d'Utilisation

Ordre de remplissage recommandé :

  1. Profil : Commencez par renseigner vos informations de base
  2. Compétences : Créez vos catégories et listez vos compétences
  3. Formations : Ajoutez votre parcours académique
  4. Projets : Créez vos projets en associant les compétences
  5. Expériences : Documentez vos expériences en les liant aux projets

Rédaction des descriptions :

  • Soyez concis mais précis
  • Utilisez des verbes d'action (développé, créé, analysé...)
  • Quantifiez vos réalisations quand c'est possible
  • Pour les expériences, listez vos réalisations ligne par ligne

Gestion des dates :

  • Laissez la date de fin vide pour indiquer "En cours"
  • Les dates sont affichées au format MM/YYYY

🔧 Maintenance

Modification de la connexion :

Pour changer les paramètres de connexion à SQL Server, éditez config.php :

$serverName = "localhost";  // Adresse du serveur
$database = "Portfolio";     // Nom de la base
$uid = "votre_login";       // Identifiant
$pwd = "votre_password";    // Mot de passe

Personnalisation visuelle :

Modifiez style.css pour changer les couleurs et styles du site.

📞 Support

En cas de problème :

  1. Vérifiez que SQL Server est bien démarré
  2. Vérifiez les paramètres de connexion dans config.php
  3. Consultez les logs d'erreur PHP
  4. Vérifiez que l'extension sqlsrv est bien chargée
Test de l'extension : Utilisez la commande php -m en ligne de commande pour vérifier si sqlsrv et pdo_sqlsrv sont listés.
